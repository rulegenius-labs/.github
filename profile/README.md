# RuleGenius Labs

We’re developing **RuleGenius**, a Minibota Labs product for documenting, reviewing, and applying data rules.

**RuleScript** is an open language for validating and transforming data. Its draft specification defines the `.rules` format and execution semantics for CSV and JSON records. The repository includes the grammar, examples, and conformance cases.

- [RuleGenius website](https://www.rulegenius.com/)
- [RuleScript specification and examples](https://github.com/rulegenius-labs/rulescript)
- [Discuss RuleScript or report an issue](https://github.com/rulegenius-labs/rulescript/issues)
